# Studio Tools
Studio name and Roblox game idea randomizers.

- [Roblox Trendslop Randomizer](game-randomizer/) — Verb / Determiner / Noun slot machine built from words in real Roblox chart titles.
- [Studio Name Randomizer](studio-randomizer/) — slot-machine generator and shortlist for choosing a game studio name. Three naming modes, editable word bank, lookup links. See [its README](studio-randomizer/README.md).
